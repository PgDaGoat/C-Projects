Rules that your identifiers must follow:
* The identifier can;t be a keyword. Keywords are reserved
* The identifier can only be composed of letter, numbers, and the underscore character
* The identifier must begin with a letter or and underscore. It can not start with a numbers
*C++ is case sensitive, and thus distinguishes between lower and upper case letters
*"nvalue" is different than "nValue" is different that "NVALUE".
Indentifier naming best practice:
* it is conventional in C++ that variable names should begin with a lowercase letter.
If the variable name is a single word or acronym, the whole thing should be written in lowercase letters.
Examples of Conventional and Unconventional Function Names:
* int my_variable_name; //conventional snake_case
* int my_funtion_name(); //conventional snake_case
* int myVariableName; //conventional camelCase/interCapped
* int myFunctionName(); //conventional camelCase
* int my variable name; //invalid(whitespaces are not allowed)
* int my function name; //invalid(whitespaces are not allowed)
* int MyVariableName; //Unconventional
* int MyFunctionName; //Unconventional
